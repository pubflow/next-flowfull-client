# Auth Flow

The starter uses `@pubflow/react` as the auth standard.

- `PubflowProvider` is configured in `src/components/providers.tsx`.
- `/login` renders `LoginForm` with env-based branding.
- If Flowless returns `requires2fa`, the package form switches to OTP verification.
- `/register` renders `AccountCreationForm` for public account creation.
- `/forgot-password` renders `PasswordResetForm` for reset requests.
- `/reset-password` is an alias for reset links generated by recovery emails.
- `/dashboard` uses `AuthGuard` and redirects unauthenticated users to `/login?redirect=/dashboard`.
- `useAuth()` exposes the full user payload returned by Flowless, so future modules can rely on instance-specific user fields.
